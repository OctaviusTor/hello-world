## Python Training Script

This repository contains a simple Python script for training a machine learning model on the Iris dataset using scikit-learn.

### Setup

1. Ensure you have Python installed.
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

### Usage

Run the training script:
```
python train.py
```

This will train a Random Forest classifier on the Iris dataset, evaluate its performance, and save the model to `model.pkl`.

### Output

- Model accuracy
- Classification report
- Saved model file

### Troubleshooting

- If you encounter import errors, ensure all dependencies are installed.
- The script uses the Iris dataset from scikit-learn, which is included.
